# v1.0.0

- Initial release for Geometry Dash **2.2081** and Geode **v5.11.2**.
- Added world-locked frame-window circles (`1F`–`12F+`) and matching colored labels on `m_objectLayer`.
- Added compact top-right counter with `Total` and per-category counts for enabled frame windows.
- Added **Fake / Visual Estimate Mode** (primary) with obstacle-clearance, speed, mini-icon, gamemode, and cadence heuristics plus Weyl equidistribution across enabled categories.
- Added **Experimental Real Analysis (Macro Scan)** mode using deterministic `[-N, +N]` step-perturbation from 0%.
- Added synthesized descending pitched ding sounds (`12F` highest pitch down to `1F` lowest pitch), custom sound support, and the descending **Sound Preview Guide (`12F -> 1F`)**.
- Added multi-format **Mega Hack Macro Import & Playback** (`.mhr`, `.mhr.json`, `.gdr2`, `.gdr` JSON & MessagePack, `.json`, `.zbf`, `.re3`, `.xd`, `.txt`).
- Added in-game **FFC Menu** (`F8` keybind / Pause Menu `"FFC"` button) and **Categories (`1F–12F+`)** customization popup.
